# UiI - UX Improvement

Buatlah logic handle untuk `btnPause` agar state timer hanya di atur dalam satu button tersebut untuk melakukan 'pause' atau 'continue'/'play' timer.

Untuk `btnStart` hanya untuk memulai timer saja saat pertama kali. Sedangkan jika timer berjalan, gunakan `btnPause` saja untuk kontrol timer.
