- Pomodoro progress tracker

Sistem dalam menyimpan progress pomodoro yang telah selesai. Setelah satu sesi pomodoro selesai, sistem akan otomatis melanjut timer dengan mode selanjutnya. Settingan auto play ini dapat di nonaktifkan. Berikut cara kerja teknis nya. User can see how much pomodoro session their have

```
IF current_mode == Pomodoro:
    session_count += 1
    IF session_count % 4 == 0:
        NEXT_MODE = LongBreak
    ELSE:
        NEXT_MODE = ShortBreak
ELSE (jika current_mode adalah Break):
    NEXT_MODE = Pomodoro

// Tentukan apakah Auto-Play
IF NEXT_MODE is Break AND auto_start_break IS ON:
    START_TIMER()
ELSE IF NEXT_MODE is Pomodoro AND auto_start_pomo IS ON:
    START_TIMER()
```

Constraint:

- Do not reset session_count unless users reset all state
- Session long break interval is not hardcoded
- Create handle for setting button in home.fxml so it can open setting menu without switching current scene.
