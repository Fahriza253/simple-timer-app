# Pomodoro Implementation

Mengembangkan aplikasi timer biasa menjadi untuk timer pomodoro

## What's new

- Add Mode Selection

User can easily switch mode between session

- Pomodoro
- Short Break
- Long Break

Each mode have default timer, but user still can change it manually for now.

- Pomodoro: 25 minutes
- Short Break: 5 minutes
- Long Break: 15 minutes

## Structure

Follow this structure to implement the concept. Correct me if im wrong.

- App.java -> Init App
- /config/PomodoroMode.java -> Interface
  |-- Pomodoro.java -> implementation for each mode
  |-- ShortBreak.java
  |-- LongBreak.java
